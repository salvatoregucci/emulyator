# Локальный демо-макет магазина

Простой макет страницы товара с редактируемыми названием, фотографией, ценой, процентом комиссии, размером и локацией. Сделан на HTML, CSS и JavaScript — ничего устанавливать или собирать не нужно.

## Запуск на компьютере

1. Откройте репозиторий `https://github.com/salvatoregucci/emulyator`.
2. Откройте файл `index.html` и нажмите **Download raw file** (или скачайте репозиторий через **Code → Download ZIP**).
3. Если скачали ZIP, распакуйте его.
4. Дважды нажмите `index.html` — файл откроется в браузере. Для удобного редактирования можно установить Visual Studio Code, но это не обязательно.

## Использование

- Введите цену товара и процент комиссии — комиссия и сумма после неё пересчитаются автоматически.
- Выберите фотографию с компьютера — она появится в предпросмотре.
- Измените название, размер и адрес/локацию.
- Нажмите **Сохранить в браузере**, чтобы сохранить настройки на этом устройстве.
- На компьютере отображается предпросмотр в узком мобильном viewport; на телефоне макет адаптируется под экран.

Процент комиссии задаётся вручную: фактические сборы зависят от сервиса и условий. Макет не отправляет данные на сервер, не принимает оплату и не связан с GOAT. Он намеренно обозначен как DEMO, чтобы его нельзя было принять за официальный сайт.
